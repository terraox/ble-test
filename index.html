TSPL over Bluetooth Low Energy: test page

Untested page. Use Chrome or Edge on desktop. Open it from http://localhost (see below), not by double-clicking the file. Close every other app that uses the printer (phone app, nRF Connect), because a BLE printer usually accepts one connection at a time.

1. Connect
2. Label and speed settings

Assumes 203 dpi (8 dots per mm). The SDK writes 20 bytes with a 30 ms pause. To test speed, raise the chunk size (for example 100, 180, 240) and lower the delay (for example 10, 0).

3. Print

The bitmap pattern has a solid black square in the TOP-LEFT corner, a border and a diagonal line. If the label comes out mostly black with a white square, switch the polarity and print again.
